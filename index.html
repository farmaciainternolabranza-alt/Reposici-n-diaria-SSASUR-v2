1. Cargar reportes

Carga ambos reportes para comenzar.

2. Tipos de documentos considerados como consumo

Las opciones se detectan automáticamente desde la columna “Tipo Documento”. Por defecto solo se seleccionan las recetas; puedes marcar otros tipos si los necesitas.

3. Asignar bodegas

Se detectan todas las bodegas del archivo. Asigna las dos que se utilizarán en el informe.

4. Generar informe

Los archivos se procesan en este navegador. No se cargan a GitHub ni a otro servidor.

Modo Droguería · Stock CESFAM

Utiliza los mismos archivos y bodegas seleccionadas arriba. El Stock CESFAM es la suma de Stock Farmacia + Stock Bodega. El consumo considera los tipos seleccionados (por defecto, recetas).
